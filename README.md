# webdev_lab1
Connect Github, git desktop and computer.
Coursera lab 1 with index file.
Steps:
Click the green button code in the repository, and keep url. Open it in gitHub and set a folder address in computer.
then, clone, and file will be on both Git Desktop and the folder on the computer.
In your PC folder, create a new text file and name it index.html (this alone won't create an HTML file; it needs to be opened in Notepad ++ and saved as hypertext markup language).
There are other ways to create an HTML file (add file? from github).
Now open the Git desktop, all the changes made in the PC folder or in Notepad++ will be shown there, so we now have the index.html file written in notepad++. 
In the left down corner of Desktop Git, commit to branch, then pull and push to main (origin), and the file will be in GitHub.Changes made on the file in Git desktop can be committed and fetched in Github.
Video part 3 to make the file live:
In GitHub, go to settings-pages. Leave deploy from branch, branch, root, save.
The link will appear at the top of the page and can be surfed (it can take a few minutes to appear).
That's it.
The rest of the video talks about browsers to test in Dev mode.
