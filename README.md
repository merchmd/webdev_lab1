# webdev_lab1
Connect Github, git desktop and computer.
Coursera lab 1 with index file.
Steps:
Click green buttom code in the repository, keep url . Open in gitHub and set a folder address in computer,
then, clone, and file will be in both Git Desktop and folder in computer.
In your PC folder create a new text file and name it index.html (this alone won't create a html file, need to be opened in notepad ++ and saved as hypertext markup language).
There are another ways to create an html file (add file? from github).
Now open the Git desktop, all the changes made in the PC folder or in Notepad++ will be shown there, so we have now the index.html file written in notepad++. 
In the left down corner of Desktop Git, commit to branch, then pull and push to main (origin), and the file will be in GitHub.Changes made on the file in Git desktop can be commited fetched in Github.
